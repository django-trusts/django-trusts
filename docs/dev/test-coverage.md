# Coverage history

Historical development record. Last source update: 2026-10-14. Reorganized
2026-10-16; this revision has not been reviewed by a human for current accuracy.

The chronological test inventory and measured statement/branch totals are
preserved in the [source snapshot](https://github.com/django-trusts/django-trusts/blob/426b7ea33f817e78290cf2e769105aaa6bfd69a5/docs/test-coverage.md).
Entries describe their own revisions; older gaps and API names are not current
contracts. Individual regression tests in `tests/core/` retain their issue
numbers and executable assertions.

Use the [development workflow](development.md#test) for running checks and the
[security audit](../../SECURITY_AUDIT.md) for the boundaries those tests protect.
Coverage percentages do not establish that the permission model is secure.
